Google Maps API Key Setup Required

An API key is required to render the interactive street map and road routing. To enable Google Maps:

  1. Open frontend/script.js
  2. Replace YOUR_GOOGLE_MAPS_API_KEY with your restricted Google Cloud API key.
  3. Ensure the Maps JavaScript API (and optionally Directions API) is enabled.

Safety Notice: All other features (database table, recommendation engine, demand forecasting, congestion alerts) remain 100% operational even without a Maps API key.
